# Image Processing & KNN Classification

Course project from UC San Diego DSC 20.

## Overview

Built an object-oriented image-processing system in Python and implemented a K-nearest-neighbors classifier for image classification.

## Features

- RGB image representation and pixel manipulation
- Grayscale conversion
- Image negation
- Brightness adjustment
- 180-degree rotation
- Pixelation
- Edge detection
- K-nearest-neighbors image classification using Euclidean distance

## Technologies

- Python
- NumPy
- PIL
- Object-Oriented Programming
- K-Nearest Neighbors

## What I Implemented

Designed reusable image-processing classes using inheritance, input validation, deep copying, and multidimensional list processing. Implemented a KNN classifier that compares images using Euclidean distance and predicts labels from the nearest training examples.
